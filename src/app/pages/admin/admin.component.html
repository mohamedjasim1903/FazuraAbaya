🛠️ Quick Fix for Firebase Storage Permission (storage/unauthorized):

Your Firebase Storage has default locked rules. To allow uploading photos directly:

  1. Go to Firebase Console → Storage → Rules
  2. Paste the contents of storage.rules (already created in your project):
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /products/{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

3. Click Publish in Firebase Console. You will immediately be able to upload images without 403 errors!
